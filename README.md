# D&D Friends 5.5 Magic Item Guide

GitHub Pages package with the Tiamat theme removed completely.

Includes:
- `index.html` — standalone application
- `assets/Ellen_Bear_render.webp` — Bear theme artwork
- `.nojekyll` — GitHub Pages compatibility

If Tiamat had been saved as the active theme in an older build, this version automatically falls back to Modern MIT.
