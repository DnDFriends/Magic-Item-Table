# D&D Friends Magic Item Guide

Static GitHub Pages build.

## This revision
- Purchase List can be switched between a normal drawer and a pinned sidebar; the pinned sidebar keeps the MIT table interactive.
- Evolving item names override attunement/theme text colors and use the evolving-item green.
- Reset now clears all application modes, including Artificer/Spreadsheet/Mobile/Simple/Shop/sidebar modes, and optionally resets the theme to Modern MIT.
- New Import / Export center supports selective JSON transfer of:
  - Purchase List & Wallet
  - MIT Filters & View
  - Modes
  - Theme & Display
  - Reward Builder
  - Favorites & Compare
- Existing Artificer Mode, Reward Builder, Shop Mode, themes, live sheet sync, responsive scaling, and Bear assets remain included.

Upload the contents of this folder to the GitHub Pages publishing root. `index.html` is self-contained except for the included Bear-theme image assets and live Google Sheet requests.
