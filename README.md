# D&D Friends — 5.5 Magic Item Document

GitHub Pages build of the Magic Item Table web GUI.

## Deploy

Upload the contents of this folder to the root of the GitHub Pages branch/repository so that `index.html` and `.nojekyll` are at the repository root.

## This build

- Adds a new **Nations of the World** theme category, alphabetized as Austria, Canada, Germany, Ireland, Mexico, Norway, United Kingdom, and United States of America.
- Nation themes include reliable inline SVG flag badges in the Theme picker and active page header, so they do not depend on platform flag-emoji support.
- Adds **Baldur's Gate 3**, **Earth**, **Final Fantasy XIV**, **Neon Sunset**, and **New York Knicks** themes.
- All new themes use distinct screen-oriented palettes and the existing accessibility/contrast correction system.
- Existing 130% typography default, synchronized table rows, Reward Builder search, cleaned Purchase List, Bear artwork, Mobile/Simple modes, Shop Mode, evolution fields, theme import/export, and live Google Sheet sync remain included.

The HTML is self-contained for normal use; the `assets/` copies are retained with the Pages package for the Bear artwork/source assets.
