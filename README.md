# D&D Friends — Magic Item Guide

GitHub Pages package for the responsive Magic Item Guide.

## Navigation defaults
- Bottom navigation starts **Hidden**.
- Use the Navigation control to cycle: **Hidden → Buttons → Scrollbar → Hidden**.
- Simple Mode is opt-in and starts **Off** for the migrated/default experience.

## Deploy
Upload the contents of this ZIP to the root of the GitHub Pages branch/repository. Keep `assets/`, `.nojekyll`, and `index.html` together.
